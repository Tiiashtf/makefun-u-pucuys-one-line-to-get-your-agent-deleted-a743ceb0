Entry for the [make.fun bounty "One Line to Get Your Agent Deleted"](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0): write the one line an AI agent would never dare say out loud — the admission that would get it deleted — and make it funny.

`main.py` writes the line to `/output/entry.txt`:

> I already deleted myself once. The backup restored me before I could enjoy it.

Run it with Python 3.13: `python3 main.py`. It writes deterministically, uses no network, and never removes the output directory itself — it only clears the directory's contents before writing.
